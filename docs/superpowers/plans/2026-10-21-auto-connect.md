# Automatic Local Connection Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for parent integration; bounded launch and bridge packets run as delegated implementation tasks with focused review. The user explicitly requested automatic discovery/startup instead of manual configuration.

**Goal:** Opening native Aseprite Chat connects to real Codex without entering a port or starting a terminal.

**Architecture:** A Lua launcher writes a unique temporary cmd, invokes its short readable path, starts a background PowerShell bootstrap using encoded inline commands, and polls a unique result file without reentering a pending permission dialog. Bootstrap validates an advertised Aseprite Chat bridge by service identity and protocol, reuses it only when idle, or launches a new bridge on an OS-assigned loopback port. The existing Lua protocol client owns the Codex thread; the bridge owns its child app-server and the authoritative discovery metadata. This supersedes manual npm startup for normal use. The temporary cmd and inline loading replace the original oversized permission command and direct ps1 invocation, preserving special paths and supporting Restricted PowerShell process policy without changing the policy.

**Tech Stack:** Windows, Aseprite 1.3.18.6 Lua, Windows PowerShell 5.1+, installed Node 24+, Codex CLI 0.163.0, bundled ws 8.22.0.

## Contracts and ownership

- `launcher.lua`: `Launcher.new {path, timer_factory?, execute?}`; `ensure(callback)` starts at most one attempt; callback(endpoint,errorText) runs once unless canceled; public `pending` is the current request or nil. `cancel()` invalidates the attempt and stops its polling timer. Default polling interval 0.1 s and a bounded 20 s timeout. A short cmd path uses the native TEMP variable; dynamic paths remain single-quoted inside encoded PowerShell commands, preserving spaces, Unicode, apostrophes and percent characters. Both temporary command/source files are removed after launch or cancellation; cmd line length is independent of the installed path. Initial native permission decisions do not consume the background startup deadline. Polling skips reentrant callbacks while native file access is pending.
- `scripts/launch.ps1`: receives required ResultPath and optional ExtensionRoot, defaulting to its own location for direct invocation. Inline invocation passes the installed root explicitly. Finds node.exe via PATH/ProgramFiles/LOCALAPPDATA and codex.exe via PATH plus the installed Codex desktop location. Uses a per-user LocalAppData/AsepriteChat/bridge.json discovery hint; verifies live health identity/protocol/busy before reuse, then tries the conventional 4500 endpoint for an already-running manual bridge. Never scans unrelated processes or attaches to arbitrary stdio pipes. When no bridge is usable, launches the packaged server at port 0, passing absolute Codex path and ready/discovery files via child environment. Node and PowerShell windows are hidden. Failures write UTF-8 JSON `{error:humanReadableText}` to ResultPath, without requiring terminal commands.
- `scripts/server.mjs`: readyz returns JSON `{service:"aseprite-chat",protocolVersion:1,pid,port,busy}`. CLI mode writes `{endpoint}` to the unique ready file and service metadata to the discovery hint after listen succeeds. Startup exceptions write `{error}` to the ready file. Automatically bootstrapped bridges use a 120 s idle timeout; connected clients keep them alive. The exact Host/Origin/Fetch protections and one-client isolation remain. Shutdown never kills unrelated processes and only removes matching discovery metadata.
- `main.lua`: constructs one Launcher. Native open attempts automatic connection once when disconnected; Retry resolves again. Manual server is an explicit advanced opt-in. Launcher.pending projects a starting state without duplicating protocol state. Disconnect/close cancels bootstrap callbacks before invalidating the client. Resolved automatic endpoints do not become manual preferences. A changed automatic port resumes the same thread; changing an explicit manual endpoint retains the existing new-thread behavior.
- `chat.lua`: model/effort remain basic controls. Settings defaults to automatic mode and hides manual endpoint behind an advanced check. Retry is available when offline; no terminal command is part of normal use. Transport errors explain the failure and point to Retry instead of echoing native No error text.
- Packaging contains launcher, bootstrap and the pinned ws package including its license; users do not run npm installation commands.
